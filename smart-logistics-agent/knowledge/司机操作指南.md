# 司机操作指南

司机是运输任务的执行者，主要操作包括货物状态上报和接收调度指令。

## 货物状态上报

司机需在运输关键节点手动上报货物状态，确保货主和调度员实时掌握运输进度。

### 状态定义

| 状态 | 含义 | 上报时机 |
|------|------|---------|
| 待装货 | 运输任务已分配，车辆尚未装货 | 任务创建后默认状态 |
| 已装货 | 货物已装车，准备出发 | 完成装货、清点无误后 |
| 运输中 | 车辆正在运输途中 | 车辆出发、离开仓库后 |
| 已送达 | 车辆到达目的地，等待卸货签收 | 到达收货地点后 |
| 已签收 | 货主确认收货，运输任务完成 | 货主在平台确认后自动变更 |

### 上报流程

1. 司机在司机端 APP 或车载终端选择当前运输任务
2. 点击对应状态按钮（已装货 / 运输中 / 已送达）
3. 可选填写备注信息（如装货数量、到达时间、异常情况说明）
4. 提交后后端接收并更新货物运输状态
5. 系统自动通知关联货主状态变更

### 上报规范

- 及时上报：到达每个节点后尽快上报，避免状态滞后导致货主误解
- 如实上报：不得提前上报未发生的状态（如未装货就上报已装货）
- 异常说明：如遇堵车、车辆故障、货物破损等异常，上报状态时应在备注中说明
- 不可跳过：状态应按顺序流转，不能从待装货直接跳到已送达

## 接收调度指令

司机在运输过程中可能收到调度员下发的指令。

接收方式：
- 司机端 APP 推送通知
- 车载终端语音或文字提示
- 紧急情况下调度员会同时电话联系

指令处理：
1. 收到指令后及时查看内容
2. 评估指令的可行性和安全性
3. 执行指令并在必要时反馈执行结果
4. 如指令无法执行（如道路封闭、车辆故障），应立即联系调度员说明情况

常见指令及应对：
- 路线调整：按新路线行驶，注意更新导航
- 临时停靠：在指定安全地点停车等待，收到继续指令后再出发
- 返航：安全掉头返回出发地，途中注意货物固定
- 联系确认：尽快回电或在平台回复调度员

## 注意事项

- 驾驶安全第一：操作司机端应在停车时进行，行驶中禁止操作手机或终端
- 设备维护：保持车载 GPS 终端通电在线，设备故障时及时上报调度员
- 货箱安全：运输途中确保货箱锁闭，发现异常开箱应立即停车检查并上报
- 隐私保护：司机端账号仅限本人使用，不得转借他人

# 智慧物流前端原型 v1.0（五角色 UI 优化版）

本版本在 v0.9 Element Plus + 高德地图版本基础上，按照 UI 原型和功能清单重新整理前端信息架构。

## 五类身份

- 货主：概览、货物追踪、运输轨迹、预计到达时间、告警通知、智能问答、我的货物、个人中心
- 司机：我的任务、运输任务、状态上报、调度指令、消息中心、个人中心
- 仓库管理员：概览、车辆管理、货物车辆绑定、入库出库、绑定记录、任务分配、个人中心
- 调度员：概览、车辆监控、告警管理、调度指令、数据统计、消息中心、个人中心
- 系统管理员：概览、用户管理、角色管理、车辆管理、货物管理、告警管理、告警日志、系统设置、个人中心

右上角点击当前用户即可切换五种身份，菜单和首页会同步变化。

## 重要约束

1. `src/components/AMapView.vue` 原文件保持不变，高德地图加载、Key、安全密钥、WGS84 -> GCJ-02 转换及车辆 Marker 逻辑未改。
2. 原 `src/style.css` 保持不变；新增 `src/role-ui.css` 只负责布局与主题覆盖，没有新增 `font-size` 规则，因此原有字号体系保持不变。
3. 高德地图环境变量仍沿用原版本：

```env
VITE_AMAP_KEY=你的高德Key
VITE_AMAP_SECURITY_CODE=你的securityJsCode
```

## 启动

```bash
npm install
npm run dev
```

或使用 pnpm：

```bash
pnpm install
pnpm dev
```

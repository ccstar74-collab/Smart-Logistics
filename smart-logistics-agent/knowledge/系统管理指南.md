# 系统管理指南

系统管理由系统管理员负责，当前阶段主要功能为告警日志查看与追溯。

## 告警日志查看

系统管理员可在告警日志页面查看所有历史告警记录。

### 日志字段

每条告警记录包含以下信息：

| 字段 | 说明 |
|------|------|
| 告警编号 | 唯一标识，如 ALERT-20260823-0001 |
| 告警类型 | 偏航 / 异常停留 / 异常开箱 |
| 关联车辆 | 车牌号和设备编号 |
| 关联货物 | 货物编号或运输任务号 |
| 发生时间 | 系统检测到异常的时间 |
| 发生位置 | 异常发生时的 GPS 经纬度及地址描述 |
| 告警级别 | 一般 / 重要 / 紧急 |
| 处理状态 | 待处理 / 处理中 / 已关闭 |
| 处理人 | 负责处置的调度员或管理员 |
| 处理意见 | 处置过程和结果的文字记录 |
| 解决时间 | 异常消除、告警关闭的时间 |

### 筛选与查询

支持按以下条件筛选告警日志：
- 告警类型：偏航、异常停留、异常开箱
- 处理状态：待处理、处理中、已关闭
- 时间范围：指定起止日期
- 车牌号/设备编号：查询特定车辆的所有告警
- 告警级别：一般、重要、紧急

### 日志详情

点击单条告警可查看详情，包括：
- 告警基本信息
- 异常发生时的车辆位置地图标注
- 异常发生前后一段时间的轨迹片段
- 完整的处理时间线（告警触发→通知发送→调度员接单→下发指令→异常消除→关闭）
- 关联的调度指令记录

## 告警统计（预留）

系统管理员可查看告警统计报表，包括：
- 各类型告警数量占比
- 告警趋势（按日/周/月）
- 高频告警车辆排名
- 平均处理时长
- 未关闭告警清单

统计数据用于发现运输管理中的系统性问题，如某条路线偏航频繁可能需要调整规划路线，某辆车异常停留多可能需要检查司机排班。

## 操作规范

- 告警日志为系统自动生成的记录，系统管理员不可修改或删除原始日志
- 关闭告警须填写处理意见，说明异常原因和处置结果
- 误报告警可标注为"误报"并说明原因，但不删除记录
- 定期导出和归档告警日志，满足企业内部审计和合规要求
- 涉及客户投诉或纠纷的告警记录应长期保存

## 与其他角色的协作

- 调度员负责告警的实时处置，系统管理员负责日志的查看、追溯和统计分析
- 系统管理员发现长期未处理的告警时，应提醒对应调度员或升级处理
- 货主可接收告警通知，但不能查看告警日志列表和其他货主的告警信息
- 告警日志中的位置数据属于敏感信息，仅限授权人员查看

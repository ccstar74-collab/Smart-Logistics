# 路线切换界面优化说明

本次只优化调度员“路线切换”交互，不改后端接口合同：

- “当前路线”不再简单显示“暂无当前路线”。当路线版本接口没有 `ACTIVE` 记录时，前端仍以运输任务的起点、终点和 `/planned-route` 返回情况展示“任务原计划路线”，并明确说明为什么没有 ACTIVE 版本。
- “目标备用路线”改为按“路线版本 + 距离 + 预计耗时”选择，不再尝试用一行道路文字描述完整路线。
- 点击“重新规划路线”后会自动识别并选中新生成的 READY 路线，并显示“新生成”标记。
- 如果当前 ACTIVE 路线和备用路线同时返回 `distanceMeters` / `durationSeconds`，页面会计算距离、预计耗时的差异；字段不足时明确提示，避免伪造差异。
- 地图同时展示原路线和多个候选路线暂未加入，本次保留后续扩展位。

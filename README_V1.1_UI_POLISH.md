# 智慧物流前端原型 v1.1 —— 页面美化与身份切换优化

本版本在 v1.0 五角色 UI 基础上继续优化视觉层次，保持既有业务功能、高德地图调用逻辑和原字号体系不变。

## 本次主要修改

1. **移除真实业务页面中的“XX端（XX视图）”标签**
   - 页面直接以“运输概览 / 我的任务 / 仓储作业 / 调度总览 / 系统总览”等业务标题呈现。
   - 当前身份通过右上角账户区自然展示，不再占用内容区空间。

2. **关键数据卡片增加统一 SVG 图标**
   - 货主、仓库管理员、调度员、系统管理员首页的关键指标卡片均加入圆角图标区。
   - 图标颜色按业务语义区分，同时保留原有文字字号。

3. **司机状态上报卡片优化**
   - “已装货 / 运输中 / 已送达”改为统一矢量图标与选中态样式。

4. **调度员快捷操作优化**
   - 下发调度指令、批量消息、数据统计增加统一图标、箭头和交互层次。

5. **身份切换弹窗重新设计**
   - 从原先五列窄卡片改为自适应卡片网格，解决文字纵向断行问题。
   - 每个身份显示角色图标、角色名称、演示账号姓名和职责摘要。
   - 当前身份有明确高亮。
   - 底部预留“后续与登录 / 注册和角色权限体系衔接”的说明，便于下一阶段接入认证页面。

6. **顶部与侧栏账户入口统一**
   - 右上角头像使用一致的文字头像样式。
   - 侧栏底部增加账户卡片，可直接打开身份切换。

## 保持不变

- `src/components/AMapView.vue` 未修改，高德地图加载、密钥配置、坐标转换、Marker 和轨迹逻辑保持原样。
- `src/style.css` 未修改，因此原项目字号定义保持不变。
- 本次新增的 v1.1 样式没有覆盖原有 `font-size`。

## 运行

```bash
npm install
npm run dev
```

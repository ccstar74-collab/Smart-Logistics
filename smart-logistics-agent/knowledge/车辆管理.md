# 车辆管理

车辆管理由仓库管理员负责，包括车辆注册、信息查看和车辆解绑。

## 车辆注册（添加车辆）

新车辆投入使用前，需在平台完成注册。

注册信息通常包括：
- 车牌号：如渝A10000，用于唯一标识车辆
- 设备编号：车载 GPS 终端的设备编码，如 sim_000，用于关联 MQTT 上报数据
- 车辆类型：厢式货车、冷藏车、平板车等
- 载重/容积：车辆的额定载重和货箱容积
- 所属车队/仓库：车辆归属的运营单位

注册流程：后台录入车辆信息 → 系统保存车辆档案 → 车载设备上线后自动关联。

注意事项：
- 车牌号和设备编号必须唯一，不能重复注册
- 设备编号需与车载 GPS 终端实际编号一致，否则无法接收定位数据
- 车辆注册后默认为离线状态，设备首次上报数据后变为在线

## 车辆信息查看

仓库管理员可在车辆列表中查看所有已注册车辆的信息。

列表展示字段：车牌号、设备编号、车辆类型、当前状态（在线/离线）、绑定货物、最后定位时间。

支持按车牌号、设备编号、状态筛选。

## 车辆解绑

车辆报废、转售或长期停用时，应在平台解绑。

解绑规则：
- 解绑前须确认车辆当前没有进行中的运输任务
- 车辆与货物存在绑定关系时，应先解除货物绑定，再解绑车辆
- 解绑后车辆不再出现在可调度列表中，但历史运输记录和轨迹数据保留
- 解绑操作记录操作人、操作时间和解绑原因

## 车辆状态说明

| 状态 | 含义 |
|------|------|
| 在线 | 车载设备正常上报 GPS 数据 |
| 离线 | 超过设定时间未收到设备上报，可能是设备断电、网络信号差或车辆停运 |
| 运输中 | 车辆已绑定货物且司机上报为运输中状态 |
| 空闲 | 车辆在线但未绑定货物，可分配新任务 |

设备离线时，调度员和货主应以页面显示的最后定位时间为准，并联系司机核实情况，不应仅凭离线状态判断车辆位置。
